# Combo Trainer voice clips

Drop one MP3 per combo here. The app plays `combos/<digits>.mp3` for each
announced combo (e.g. combo [1,2,3] → `1_2_3.mp3`). If a clip is missing, the
app falls back to the device TTS voice, so the feature always works.

**Format:** MP3, mono is fine, normal speaking volume, no long leading/trailing
silence. Generate with a premium AI voice (e.g. ElevenLabs), English.

Punch numbering: 1 Jab · 2 Cross · 3 Lead Hook · 4 Rear Hook ·
5 Lead Uppercut · 6 Rear Uppercut.
